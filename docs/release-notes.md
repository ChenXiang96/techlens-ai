## What this preview contains

- English local browser and terminal workflows without credentials.
- Preparation/download of one-to-three-candidate requests with optional team context,
  exact Decimal constraints and explicit USD 0 beginner examples.
- Package-owned fictional single/comparison/partial demonstrations through the real
  retained plan-review workflow: Approve/Reject and validated Modify/preview/Apply/Cancel.
- Readable summary/full thirteen-section reports, evidence references, limitations,
  accounting qualifications and canonical local downloads.
- Safe default high loopback ports, bounded retained state and explicit restart/loss.

Custom requests are prepared only; they are never attached to canned demo results.
Demo data, usage and prices are fictional. Citation integrity is not semantic support
or factual truth. No provider request or live authorization is part of the quickstart.

## Installation and use

Use the specifically reviewed local `techlens-0.1.0-py3-none-any.whl` or source archive;
no public download URL or registry package is established. Follow [installation](../README.md#install-into-a-chosen-environment)
with the selected environment's interpreter, then run `python -m techlens doctor`
and `python -m techlens ui` from that environment. Open the printed loopback URL and
keep the terminal open. Follow [the walkthrough](offline-walkthrough.md) for review
and report/download actions. A positive budget grants no permission.
